# Help — Available Slash Commands

Display the following list of available slash commands to the user. Do not do anything else — just show the list exactly as written below.

---

## Superpowers Skills (work on iPhone and web)

| Command | What it does |
|---|---|
| `/help` | Show this list of available commands |
| `/brainstorming` | Explore and design an idea before writing any code |
| `/dispatching-parallel-agents` | Run multiple agents in parallel on independent tasks |
| `/executing-plans` | Execute a written implementation plan step by step |
| `/finishing-a-development-branch` | Wrap up a branch: review, clean up, prepare for merge |
| `/receiving-code-review` | Respond to code review comments on a PR |
| `/requesting-code-review` | Request a code review on your current changes |
| `/session-start-hook` | Set up a SessionStart hook for this repository |
| `/subagent-driven-development` | Break a task into subagents and execute in parallel |
| `/systematic-debugging` | Methodically diagnose and fix a bug |
| `/test-driven-development` | Write tests first, then implement to make them pass |
| `/using-git-worktrees` | Work with git worktrees for parallel development |
| `/using-superpowers` | Learn how to find and use skills |
| `/verification-before-completion` | Verify work is correct before marking a task done |
| `/writing-plans` | Write a detailed implementation plan |
| `/writing-skills` | Create a new skill |
| `/simplify` | Review changed code for reuse, quality, and efficiency |
| `/commit-message` | Write a clear, well-structured git commit message |

## Notes

- These commands work in the iPhone app, Claude Code web, and the CLI.
- Standard CLI-only commands (`/clear`, `/compact`, `/cost`, etc.) are **not available** on iPhone.
- To add new skills, use `/writing-skills`.
